Projects

Central Superstore — SQL Data Warehouse & Business Analytics

Designed and built a retail analytics data warehouse in SQL Server, turning raw transactional sales data into a reporting-ready star schema, then used it to answer real profitability and performance questions.

  • Modeled a star schema: 1 fact table and 4 dimension tables (Customer, Product, Date, Location), with primary/foreign key relationships.
  • Wrote 18 analytical SQL queries covering joins, CASE-based segmentation, subqueries, and 2 CTEs.
  • Built a KPI view and a parameterized stored procedure for on-demand customer sales reports.
  • Added indexing and validated the pipeline end-to-end (staging → dimensions → fact table) with zero data loss.
  • Surfaced business insights, e.g. one region drove over half the company's profit losses despite leading in sales, traced back to excessive discounting.
